Glycan Mass Spec Annotator

Match observed m/z peaks against theoretical monoisotopic masses of candidate glycan compositions. No server, account, or installation required.

1. Peaks & search settings

One m/z per line, or CSV/TSV with optional intensity. Up to 5,000 peaks (1 MB).

2. Maximum residue counts

Assumes underivatized, free/released glycan compositions including terminal H₂O. This is a composition-mass screen, not a structure assignment, fragmentation predictor, or identification confidence score.

3. Candidate annotations

Matches are ranked by absolute ppm error. Multiple compositions can have indistinguishable m/z; every result requires independent experimental validation.

Enter peaks and select Annotate peaks, or load the example to inspect the output.

All data stays in this browser tab; no files or peak values are uploaded. Inputs and results are not stored. This static application runs without Python; the repository's separate CLI and FastAPI workflows require a Python runtime.

Mass convention: Hex 162.0528234315, HexNAc 203.0793725330, Fuc 146.0579088090, NeuAc 291.0954165270, NeuGc 307.0903311490 Da (residues); +H₂O 18.0105646840 Da. Ion m/z uses proton or sodium-cation adduct masses. Structural isomers, derivatization, isotope envelopes and tandem-MS fragment assignment are not modeled.
